Visão geral

O bot combina três blocos simples:

  • ◆ Orquestração de fluxo (n8n) — recebe a mensagem do Telegram, prepara o texto e devolve a resposta.
  • ◆ Fonte de dados meteorológicos — a API da OpenWeather, que retorna a temperatura atual da cidade.
  • ◆ Formatação da resposta — monta uma mensagem curta e clara com a cidade e a temperatura em graus Celsius.

Não há inteligência artificial nem memória: o bot é sem estado — cada mensagem é tratada de forma independente.

Fluxo de uma mensagem

Entrada

Mensagem do usuário

O usuário envia o nome de uma cidade pelo Telegram.

Etapa 1 — Captura

Texto vira a variável "queue"

A mensagem recebida é guardada na variável usada para a consulta.

Etapa 2 — Normalização

Limpeza do texto

Remove espaços extras, tira acentos, deixa em minúsculas e garante o país (Brasil).

Etapa 3 — Consulta

OpenWeather

Consulta a temperatura atual da cidade na API pública da OpenWeather, em Celsius e em português.

Etapa 4 — Validação

A cidade foi encontrada?

Verifica se a resposta trouxe uma temperatura válida (ver os dois caminhos abaixo).

Saída

Resposta no Telegram

Envia a temperatura formatada ou a mensagem de orientação.

Dois caminhos possíveis

Cidade encontrada

A API retornou a temperatura. O bot responde:
🌤️ A temperatura em [Cidade] é de [X]°C.

Cidade não encontrada

A API não localizou a cidade (nome inválido, saudação, cidade fora do Brasil). O bot responde:
❌ Cidade não encontrada. Use o formato Cidade,UF,BR.

Cuidados do projeto

🎯Escopo fechado

O bot trata só temperatura de cidades do Brasil; a mensagem de erro orienta o formato correto.

🔑Chave protegida

A chave da API não fica no fluxo exportado: é lida de uma variável de ambiente / credencial, fora do código.

🛡️Tratamento de erro

Falhas da API ou cidade inexistente são desviadas para a mensagem de orientação, sem quebrar o bot.

⚡Simples e determinístico

Sem IA e sem memória: mesma entrada, mesma saída. Fácil de auditar e barato de rodar.

Este documento descreve a arquitetura de forma conceitual. Chaves e credenciais não são divulgadas por segurança.
